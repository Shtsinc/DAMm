## 🎵 **КАК ТЕСТИРОВАТЬ АУДИОСИСТЕМУ:**

### **Шаг 1: Подготовка аудиофайлов**
Поместите OGG файлы в папку:
```
.minecraft/DynamicAmbienceAndMusic/assets/daam/sounds/
```

**Примеры файлов для тестирования:**
- `example_day_music.ogg` - дневная музыка
- `example_night_music.ogg` - ночная музыка  
- `example_day_ambient.ogg` - дневные звуки
- `example_night_ambient.ogg` - ночные звуки

### **Шаг 2: Использование тестовых команд**

#### **🔧 Команда для тестирования:**
```
/daam test
```
**Что делает:**
- Создает тестовый регион 10x10x10 блоков вокруг игрока
- Устанавливает пути к примерным аудиофайлам
- Активирует воспроизведение звуков
- Показывает сообщение в чате об успехе

#### **⏹️ Команда для остановки:**
```
/daam stop
```
**Что делает:**
- Останавливает все звуки региона
- Очищает текущий регион
- Показывает сообщение об остановке

### **Шаг 3: Проверка работы**

**✅ Ожидаемое поведение:**
1. После `/daam test` должны начать играть звуки
2. При смене времени (день/ночь) должна меняться музыка
3. В логах должны появиться сообщения:
   ```
   [DAAM] Loaded X sound files: [example_day_music, example_night_music, ...]
   [DAAM] Entering region: Test Region
   [DAAM] Playing day music: example_day_music
   ```

## 🌅 **ТЕСТИРОВАНИЕ ДЕНЬ/НОЧЬ СИСТЕМЫ:**

### **Команды для смены времени:**
```
/time set day     # Переключить на день (звуки дня)
/time set night   # Переключить на ночь (звуки ночи)
```

### **Проверка переключения:**
- **День (6:00-18:00):** играет `example_day_music` + `example_day_ambient`
- **Ночь (18:00-6:00):** играет `example_night_music` + `example_night_ambient`

## 📝 **ПРОВЕРКА REGIONEDITOR:**

### **Теперь RegionEditor должен работать правильно:**

1. **Создайте тестовый регион:** `/daam test`
2. **Возьмите RegionEditor:** `/give @p daam:region_editor`
3. **Правый клик:** должен открыться GUI с **реальными данными** тестового региона
4. **Поля должны содержать:**
   ```
   Region Name: Test Region
   Day Music Path: example_day_music
   Night Music Path: example_night_music
   Day Ambient Path: example_day_ambient
   Night Ambient Path: example_night_ambient
   ```

**❌ Если все еще показывает "Temporary Region"** - значит RegionHandler.currentRegion = null

## 🔍 **ДИАГНОСТИКА ПРОБЛЕМ:**

### **Звуки не воспроизводятся:**

#### **1. Проверьте логи (F3):**
Должны быть сообщения:
```
[DAAM] Loaded 4 sound files: [example_day_music, example_night_music, ...]
[DAAM] Entering region: Test Region
```

#### **2. Проверьте файлы:**
- Файлы должны быть в формате **OGG Vorbis**
- Находиться в папке `DynamicAmbienceAndMusic/assets/daam/sounds/`
- Названия файлов должны точно совпадать с путями в регионе

#### **3. Проверьте звуковые настройки:**
- Громкость музыки и звуков в настройках Minecraft
- Убедитесь что другие звуки в игре работают

### **RegionEditor показывает "demo mode":**
- Убедитесь что выполнили `/daam test` ПЕРЕД открытием RegionEditor
- Проверьте что стоите в области тестового региона (10x10x10 от точки создания)
